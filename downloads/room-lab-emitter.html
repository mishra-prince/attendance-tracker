If corridor phones receive the expected code, that is a failed room-boundary test. Lowering volume until legitimate seats fail does not solve it.

This page sends no network requests and does not use a camera or microphone. The 16-bit study code and CRC are public test data, not authentication or a production attendance protocol. No attendance is awarded.
